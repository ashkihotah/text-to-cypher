# Text-to-Cypher: Feasibility Analysis

This document provides a feasibility analysis of the Text-to-Cypher project, evaluating its potential to convert natural language queries into Cypher queries for graph databases. The analysis covers the project's objectives, technical challenges, and potential solutions.

## Project Objectives

The Text-to-Cypher task aims to develop a system that can accurately translate natural language queries into Cypher queries. This primarily involves two main sub-tasks:

## Major Challenges

1. **Lack of reliable Cypher Query Similarity Metrics**
2. **Lack of reliable Relevant Schema Extraction methods from a Cypher query** in order to assess performance metrics on the schema retrieval sub-task
3. **Lack of comprehensive data for training and evaluation**
4. **Lack of "native" models for Cypher query generation**
